# Internship JD Analyzer

![Status](https://img.shields.io/badge/status-live-b05830) ![Gemini](https://img.shields.io/badge/AI-Gemini%202.0%20Flash-4285F4) ![HTML](https://img.shields.io/badge/built%20with-HTML%2FJS-orange)

> Agent #25 of 100 | 100 AI Agents Challenge

Paste any internship job description + your background and get a full decode: match score, skill-by-skill breakdown, hidden expectations, action plan, resume keywords, and a "should I apply?" verdict.

## Features
- Match score with animated progress bar
- Skill-by-skill breakdown table
- Hidden expectations decoder
- 3 ranked actions to take before applying
- Red flag detector for sketchy JDs
